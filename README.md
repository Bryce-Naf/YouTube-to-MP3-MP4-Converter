# YouTube-to-MP3-MP4-Converter
An application to convert a YouTube URL into an MP3 or MP4 file.
## Project Description
My project proposal is a web application that will take a YouTube video and convert it into a downloadable MP3/MP4 file for free. This application will allow for YouTube videos to be downloadable much easier than is offered by YouTube themselves. The big problem with downloading YouTube videos is that it is not an easy process to work with, so my goal is to make this application that will assist in the process of taking a video and making it available to download to a personal device.
## Technology Stacks
- Frontend: HTML, CSS, and JavaScript
- Backend: Python, Flask, and REST API
- Database: SQLite and SQAlchemy
- Deployment: Docker, Google Cloud Run, and GitHub Actions
- Development/AI Assistance: GitHub Copilot
